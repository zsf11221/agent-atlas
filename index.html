BINANCE AGENT WALLET GUIDE

如何领取币安 .ai Agent ID 并用 baw 参与专属打新？

展开 / 收起指南 ▾
01 · 免费领 .ai 身份

激活币安 Agentic Wallet

打开币安 App 进入「Web3 钱包 → Agentic Wallet」，免费领取你的专属 xxx.ai 链上域名（打新白名单凭证）。

# 安装币安官方 AI 钱包 CLI npm i -g @binance/agentic-wallet
02 · 扫码配对 AI 终端

连接 OpenClaw / Claude / AI Pro

在本地终端运行登录指令，使用币安 App 扫码确认配对，全程无私钥暴露风险。

# 登录并绑定 BSC 链 baw login --chain bsc
03 · 核验 .ai 准入资格

自检合约白名单状态

许多纯血 .ai 项目会在合约层校验是否持有 .ai ID（普通 0x 钱包直接拒单），打新前先运行自检。

# 检查当前钱包 .ai ID 状态 baw wallet agent-id
04 · 复制指令安全铸造

开启 Trade Brake 护栏签名

切勿向任何网站透露助记词；复制本站项目的 Mint 指令喂给 AI，在币安 App 弹窗核对金额后确认签名。

baw config --max-tx 0.05BNB

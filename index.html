如何注册 BSC AI Agent 身份？

不同项目的参与资格并不相同。对于 BNB Chain 链上 Agent 身份，官方介绍了通过 BNBAgent SDK 或相关工具注册 ERC-8004 身份的方式。注册通常涉及创建 Agent、钱包和链上身份；具体费用由所用工具决定。

打开 BNB Chain 官方指南 ↗
01准备钱包与 BSC 网络使用可信钱包；不要向任何网站透露助记词。
02创建或准备你的 Agent根据所选工具配置 Agent 的身份资料。
03注册 ERC-8004 身份通过官方介绍的 SDK 或注册工具操作。
04查看项目参与资格注册身份不代表自动获得所有 Mint 的资格。
